# Internship API Task

This is a Node.js-based API project made for an internship assignment.  
It has login, logout, API calling with caching, latency tracking, and a cache reset route.

## Features

- User login with JWT token
- Logout with token blacklisting
- API data fetch (with caching using LRU cache)
- Latency tracking (with p90 calculation)
- Route to reset the cache and stats

## Technologies

- Node.js
- Express.js
- JWT (jsonwebtoken)
- LRU-cache
